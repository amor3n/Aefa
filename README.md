# Aefa
Another Engine For AI
- the Goal of this project is to create an engine to be used for any Frontend devices
## Tech Stack
[ Axum (Rust) Backend Framework | Postgres for memory management ]

### Features
- modular agentic process [ basically a modules for custom made agents that will use the selected model ]
- developer's full parameter control for the engine 
- download checksum data validation

### Phase 1 
- project structure
- setup axum
- implement api for url download for model & engine
